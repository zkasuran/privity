Privity.

Both legs of a tokenized fund trade settle in one Canton transaction, and each counterparty sees only the parcel it is buying.

Delivery versus payment removes the window where one leg has moved and the other has not. Doing it on a broadcast ledger would publish every investor's position to every other investor, which a regulated fund cannot accept. Canton is where both properties hold at once.

The three things this proves

checking

Settlement is atomic

The share leg needs the seller's authority. The cash leg needs the buyer's. One transaction carries both, so it commits whole or not at all.

checking

Disclosure is calibrated, not maximal

The buyer must verify what it is paying for, so it has to read something. It reads exactly one parcel. The seller's retained position is never disclosed.

checking

A failed leg settles nothing

When the buyer cannot cover the consideration the whole transaction is rejected and the parcel is still the seller's, undelivered. Proven by test rather than asserted.

    Run it yourself

    canton-devkit localnet up privity
dpm build --all
cd tests && dpm test          # 15 tests
canton-devkit localnet dar upload disclosure/.daml/dist/privity-disclosure-1.0.0.dar --instance privity
canton-devkit localnet dar upload app/.daml/dist/privity-1.0.0.dar --instance privity
eval "$(canton-devkit localnet env privity)"
node api/ledger.mjs demo        # the flow above, against your own participant
    What is real and what is not. Every number, contract id and transaction id on this page came out of a real Canton participant. Nothing is mocked and no output is retyped. Two things are honestly incomplete: the NAV holdings digest is a placeholder string rather than a hash computed over real holdings, so verifiable NAV is a design and not yet a feature, and the auditor is entitled to the mandate and the attestation rather than to individual positions, which is the intended need-to-know posture rather than a limitation. Replay mode shows a recorded verified run so a reader with no Docker can still see genuine ledger data. Live mode talks to a participant on your own machine.
